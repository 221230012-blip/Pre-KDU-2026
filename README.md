# Python Movie Streaming Analytics

## 📌 Overview
This exercise introduces basic Python programming concepts through a simple **Movie Streaming Analytics** theme.  
It focuses on string handling, input/output operations, and logical comparisons.

The exercise is designed to help beginners understand how Python handles strings and conditions.

---

## 🧩 Part 1: Password Validator

### Description
A user creates an account by entering their password twice.  
The program checks:
- Length of both passwords
- Whether the lengths match
- Whether both passwords are exactly the same

---

### Concepts Used
- `input()`
- `len()`
- String comparison using `==`
- Boolean expressions
- Console output using `print()`

---

- `password_validator.py`

## 🧩 Part 2: Genre Preferences

### Description
10 users select their favorite movie genres.  
The program:
- Stores all genre selections
- Identifies unique genres
- Counts how many times each genre is selected

---

### Concepts Used
- `list` (to store all selections)
- `set` (to store unique genres)
- `dictionary` (to count genre frequency)
- Loops and conditional statements

## 🧩 Part 3: Top Watched Movies

### Description
A CSV file contains movie titles watched by users.  
The program analyzes this data to determine the **top 3 most watched movies** along with their watch counts.

---

### Concepts Used
- File handling using `open()`
- String processing using `split(",")` and `strip()`
- `dictionary` for frequency counting
- Sorting using `sorted()` with `key` and `reverse=True`

---

### Files
- `top_watched_movies.py`
- `watchlist.csv`
