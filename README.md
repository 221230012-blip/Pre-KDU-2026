# 🎬 Movie Watchlist (React)

A simple and interactive **Movie Watchlist application** built using **React**.  
This app allows users to add movies they want to watch, assign ratings, search movies, delete individual entries, and clear the entire watchlist.

---

## 📌 Features

- ➕ Add movies to the watchlist
- ⭐ Assign ratings (1–5 stars)
- 🔍 Search movies (case-insensitive, real-time)
- 🗑️ Delete individual movies
- 🧹 Clear entire watchlist
- 📊 Display total movie count
- 🎨 Modern UI with gradient background and card layout
- ⚠️ Validation for empty movie names
- 📭 Empty state message when no movies exist

## ▶️ How to Run the Project (Using IntelliJ)

1. Open **IntelliJ IDEA Ultimate**
2. Open the project folder `movie-watchlist`
3. Open `package.json`
4. Click the **green ▶ Run** button next to: "start": "react-scripts start"
5. The app will open automatically in your browser at: http://localhost:3000
